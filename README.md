# Пасть Бездны

Головоломка с падающими блоками в стиле хоррор: фигуры — глиняные зубастые монстры,
поле 10×20 внутри огромной пасти. Собранный ряд пасть проглатывает, и у монстров
пропадает только та часть тела, что попала в ряд.

## Как играть
- Кнопки внизу: ◀ ▶ сдвиг, ▼ ускорить падение, ⤓ бросить вниз, ⟳ повернуть.
- Жесты на поле: тап — поворот, свайп в сторону — сдвиг, резкий свайп вниз — бросок.
- На компьютере: стрелки, пробел (бросок), Z/X (поворот), P (пауза).

## Как устроено
- `index.html` — страница игры.
- `src/game.js` — весь код игры (Phaser 3, лежит в `vendor/`).
- `assets/` — монстры (нарезаны на клетки), фон, звуки и музыка.

Запуск на компьютере: `python3 -m http.server` в этой папке, затем открыть http://localhost:8000.
